| URL / Якорь | Назначение |

## API-эндпоинты (бэкенд Express)

| Метод | Эндпоинт | Назначение | Безопасность |
|---|---|---|---|
| GET | `/api/health` | Проверка работоспособности сервера | — |
| GET | `/api/reviews` | Получить список опубликованных отзывов | Только чтение |
| POST | `/api/leads` | Отправить заявку на ремонт (создаёт тикет DRT-XXXX) | Whitelist-валидация полей, параметризованные запросы |
| GET | `/api/tickets/:code` | Проверить статус квитанции по коду DRT-XXXX | Формат-валидация кода |
| GET | `/api/account/orders` | Получить заказы текущего пользователя (Firebase Auth) | Требуется Firebase токен |
| PATCH | `/api/account/orders/:id/status` | Обновить статус заказа (мастер/админ) | Требуется Firebase токен + ownership check |
| POST | `/api/account/reviews` | Оставить отзыв о ремонте (только авторизованные) | Требуется Firebase токен, whitelist-валидация |

## Структура базы данных (PostgreSQL)

| Таблица | Назначение |
|---|---|
| `users` | Клиенты (Firebase UID, email, имя) |
| `repair_requests` | Заявки/заказы (код DRT-XXXX, статус, оценка, заметки) |
| `reviews` | Отзывы клиентов (автор, район, предмет, описание, результат) |
| `accounts` | Сессии пользователей |
| `sessions` | Токены аутентификации |
| `verification_tokens` | Токены верификации email |
